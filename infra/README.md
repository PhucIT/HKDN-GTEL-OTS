# Hạ tầng
Tài liệu hạ tầng dự kiến; chưa cấu hình triển khai.
Docker Compose là đề xuất cho phát triển, file gốc hiện chỉ có `services: {}`.
Cần chốt image/phiên bản, mạng, cổng, volume và cách cấp bí mật trước triển khai.
Không chạy Docker hoặc kết nối database trong lần dựng khung.
Xem [database](database/README.md).
