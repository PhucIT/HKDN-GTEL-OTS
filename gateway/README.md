# Gateway
Điểm vào API dự kiến bằng Nginx; chưa chốt phiên bản, đường dẫn, upstream, cổng hoặc chính sách.
`nginx.conf` chỉ có TODO, chưa phải cấu hình chạy được.
Sau khi duyệt hợp đồng, thống nhất định tuyến, header, lỗi và timeout với nhóm.
Gateway không thay thế kiểm tra quyền dữ liệu tại core-service.
