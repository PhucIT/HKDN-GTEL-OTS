# Scripts
Nơi bổ sung công cụ phát triển sau khi thống nhất; chưa có script vận hành.
Mỗi script cần mô tả mục đích, đầu vào, môi trường, tác động và cách kiểm tra.
Không tự reset/clean/stash công việc, ghi bí mật hoặc tác động database thật.
Không dùng script để giả lập việc hệ thống đã chạy được.
