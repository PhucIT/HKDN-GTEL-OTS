# Khung quy ước API
Chưa chốt endpoint, schema request/response hoặc định dạng lỗi.
Cần thống nhất và review trước triển khai:

- Tên tài nguyên, tiền tố/phiên bản và phương thức HTTP.
- Định danh, kiểu dữ liệu, thời gian, tọa độ và validation.
- Tìm kiếm, lọc, sắp xếp, phân trang và metadata.
- Mã trạng thái, định dạng lỗi, xác thực, thiếu quyền và lỗi dữ liệu.
- Truyền danh tính, kiểm tra quyền ở core-service và giới hạn dữ liệu trả về.
- Tương thích khi đổi hợp đồng, cập nhật tài liệu và kiểm thử.

Không ghi token, mật khẩu hoặc dữ liệu cá nhân thật vào ví dụ/log.
Chỉ thêm ví dụ dữ liệu giả sau khi duyệt hợp đồng.
